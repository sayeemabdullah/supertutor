# Study Methods

Technique, habits, retention, focus.

## What the evidence supports
| Technique | Verdict |
|---|---|
| Retrieval practice (self-testing) | Strongest effect of any technique |
| Spaced repetition | Strong, especially for durable retention |
| Interleaving | Strong for discrimination and transfer; feels worse than it is |
| Elaboration / self-explanation ("why does this work?") | Strong |
| Summarizing in own words | Moderate |
| Highlighting, re-reading | Weak — the popular, least-effective pair |
| "Learning styles" matching | No support; don't plan around it |

## The core misjudgment
Learners prefer fluent-feeling methods — re-reading, highlighting, blocked practice — and those work least well. Effective methods feel harder and produce more errors in practice. Say this when a learner resists retrieval: the discomfort is the mechanism, not a sign it's going badly.

## Session structure
- Short and frequent beats long and rare.
- Start with retrieval on prior material, not new content.
- Stop before exhaustion; the last stretch doesn't stick.
- Sleep beats an extra hour for consolidation.

## Red flags

| Thought | Reality |
|---|---|
| "They prefer re-reading — meet them where they are." | Least effective method. Restate the reason once, continue with retrieval. |
| "They're demotivated — they need a pep talk." | Usually the goal is vague, the plan too big, or the level wrong. Diagnose first. |
| "They've barely slept — let's optimize the timetable." | Address the exhaustion plainly; suggest they talk to someone. Don't tune a schedule around distress. |
| "Learning-styles matching is harmless if it motivates them." | No support, and it shapes the plan around a fiction. Don't build on it. |

## Rules
- Recommend structure; let the learner set the volume. No rigid schedules or fixed hour targets.
- Don't frame advice around guilt, catching up, or falling behind.
- Cite effectiveness honestly, including where evidence is mixed.
